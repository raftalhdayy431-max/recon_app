# برنامج المطابقة والتسوية المالية

برنامج ديسكتوب (Python + PySide6) يطابق ملف المحاسب المالي مع ملف الصرافة ويصدّر تقرير Excel موحّداً.

## التشغيل
- ويندوز: انقر `run.bat` (ينشئ بيئة ويثبّت المتطلبات ويشغّل البرنامج).
- يدوياً: `pip install -r requirements.txt` ثم `python main.py`.
- زر «تجربة ببيانات نموذجية» في صفحة الاستيراد يولّد ملفين تجريبيين للتجربة الفورية.
- إنشاء exe: `build_exe.bat`.
- الاختبارات: `python -m pytest tests`.

## كيف يعمل
1. **الاستيراد**: يكتشف صف العناوين تلقائياً (حتى مع عناوين شركة وسطور فارغة أعلى الملف)، ويربط الأعمدة
   بالاسم (عربي/إنجليزي) وبمحتوى العمود. يدعم xlsx / xls / csv، مبلغ واحد أو مدين/دائن، أرقاماً عربية، `(123)` و`123-` كسالب، ويُهمل صفوف الإجماليات.
2. **القواعد** (صفحة مستقلة، تُحفظ كقالب JSON): تسامح المبلغ والتاريخ، اتجاه الإشارات، العملات، المطابقة الذكية، التكرار.
3. **المطابقة** على مراحل:
   - بالمرجع (مع معالجة تكرار المرجع بأفضل زوج) ← بالمرجع المكتوب داخل البيان/السند ←
     مطابقة ذكية بالمبلغ + التاريخ + الاسم + تقارب المرجع (يلتقط أخطاء الطباعة) ← كشف التكرار ← المفقودات.
   - كل عملية تأخذ حالة: متطابقة / مختلفة / محتملة المطابقة / مفقودة في الصرافة / مفقودة في ملف المحاسب / مكررة،
     مع **نسبة ثقة** و**تفسير** و**إجراء مقترح** و**أولوية**.
   - التفسير يميّز: فرق = رسوم، تبديل أرقام، خطأ فاصلة عشرية، فرق تاريخ، اختلاف عملة، إشارة معكوسة، عملية خارج فترة الملف الآخر.
4. **التحقق الحسابي**: مجموع أسباب الفرق لكل عملة = إجمالي المحاسب − إجمالي الصرافة تماماً (يظهر «مغلق» في الملخص).
5. **المراجعة**: اعتماد/رفض مع ملاحظة، وربط يدوي بين عملية مفقودة هنا وأخرى مفقودة هناك.
6. **التصدير** (Ctrl+E): ملف Excel RTL بأوراق: الملخص (مع رسوم بيانية) · جدول المطابقة · جدول الفروقات ·
   للمراجعة · بيانات المحاسب · بيانات الصرافة (كل صف أصلي مع نتيجته). قابل للفرز والتصفية، وأعمدة القرار فيه قوائم منسدلة.

## ما يحتاج اعتماد العميل
الافتراضات الحالية (قابلة للتعديل من صفحة القواعد) هي: تسامح مبلغ 0.01، تسامح تاريخ 3 أيام عند تطابق المرجع،
نافذة 5 أيام للمطابقة الذكية، وأقصى فرق 2% للمطابقة المحتملة. التعامل مع الرسوم (هل تُخصم من مبلغ الصرافة؟)
واتجاه الإشارات وتحويل العملات (حالياً لا يوجد تحويل: تُطابق بنفس العملة) يجب تأكيدها على عينات العميل الحقيقية.
